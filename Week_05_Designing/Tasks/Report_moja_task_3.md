Pri pôvodnom postupe som najskôr viedol dlhšiu diskusiu
architektúrach:
- modulárny monolit,
- mikroservisy,
- serverless/event-driven architektúra.

## 2. Práca s novým skillom

Nový skill rozdelil rozhodovanie na jasné kroky:

1. pochopenie požiadaviek projektu,
2. určenie rozhodovacích kritérií,
3. vytvorenie troch architektonických alternatív,
4. ich porovnanie pomocou rozhodovacej matice,
5. výber najvhodnejšej architektúry,
6. vytvorenie ADR s dôsledkami a podmienkami prehodnotenia.

Skill to všetko náramne zrýchlil, pričom agent pochopil Teamify oveľa rýchlejšie.

Nepáči sa mi, že agent na konci ADR uviedol otvorené otázky. Pôsobí to, akoby architektonické rozhodnutie ešte nebolo úplne uzavreté.
