## Task 3
- Awarded: 1b   (max 1b)
- Commentary: The student proposed a new metric - SQL query length measured as SQL token count - using a simple regex heuristic `[^\s,;.]+`. The metric is well-argued: it penalizes overly long queries and complements (rather than replaces) the accuracy metric, since query length alone says nothing about correctness. The student acknowledges the heuristic's limitations (exact SQL tokenization would require a more complex parser). The implementation in evaluate_prediction_length.py reads prediction CSV files, counts tokens per query, and calculates total, average, minimum, and maximum values. Metric values were calculated for all six prediction sets and are reported in Metrika.md with a comparison across prompts (e.g., data-rtf-2 had the longest average at 51.94 tokens/155 queries, data-prime the shortest at 28.96). The report includes both numeric results and qualitative analysis of which prompts tend to produce longer or shorter queries.
